# Заметки по проекту (для продолжения работы в новой сессии)

## Что это
Новый сайт median.agency по дизайну и ТЗ 2019 года (TZ_site_median.pdf в Google Drive, папка Median_site).
Статика без сборки: `index.html` + `css/style.css` + `css/fonts.css` + `js/main.js` + `fonts/` + `media/`.
Деплой: GitHub Pages через Actions при пуше в `main`. Адрес: https://nazyrovruslan.github.io/median-site/

## Правила работы
- Правки готовить локально, показывать, что изменилось; пушить/деплоить только по явной команде Руслана.
- После правок в CSS/JS поднимать номер `?v=` у подключений в `index.html`, иначе GitHub Pages до 10 минут отдаёт браузеру старый файл из кэша.
- Шрифты: заголовки Druk Wide Cyr Bold (700) и Medium (500), текст Euclid Circular A 400/500/700. Лежат в `fonts/`.
- Заголовки разделов — переменная `--h2`; контурные слова — класс `.o` (text-stroke).
- Сетка десктопа (≥821px) как в макете median_site 2.ai: поля `--gutter` = 1/12 ширины, между ними 5 колонок по 1/6 (на 1920: 160 + 5×320). Шапка и баннер используют свои поля `--pad`. Кегли на 1920: заголовки 95px (`--h2`), крупный текст 38px (`--lead`), карточки 17px (`--txt`), подписи 18px (`--ui`).

## Структура главной (сверху вниз)
1. Баннер: слайдер кейсов (массив `HERO` = первые 5 из `CASES`), слева чёрная полоса под логотип, снизу чёрная панель с Follow us и прогресс-баром (бар — скраббер пальцем/мышью).
   Плашка «Следующий проект» в правом нижнем углу (21% × 41% экрана, всегда с превью). Переход: плашка целиком переезжает на место баннера, новая плашка вырастает из угла (JS-цикл, `go()`).
   Десктоп: удержание мыши на обложке открывает кейс (кольцо-прогресс). Тач: тап. Свайп только справа налево.
2. LIVE COMMUNICATIONS — бегущая строка на JS (без швов). Клик → шоурил (свой mp4 в панели `#reelPanel`). На тач-экранах у центра экрана слово LIVE заливается превью.
3. «Волны» — 4 контура из PDF визитки (`CARD`), в покое поочерёдно дышат, по ховеру/у центра экрана (тач) собираются в идеальные круги; на тач после полной метаморфозы в центре появляется бейдж «О нас».
4. «Внешним или внутренним» + кольцо «Все проекты» (магнит).
5. Три направления (серые экраны с сеткой): Внешние / Внутренние / Out of the list.
6. Все кейсы — список с фильтрами; на тач превью появляется у строки, проходящей центр экрана.
7. Собственные проекты: South HUB, Event Surfing (кейс `es`).
8. Футер Start a project (магнитный плюс, бриф в панели), строка: mailto → Follow us (раскрывается в строку) → © Median Agency.

## Страница кейса (панель `#casePanel`)
Обложка — во весь экран, как в прошлом варианте (решение Руслана 04.10): фото на фоне, внизу «Кейс», заголовок (строки сплошные/контурные), подзаголовок, направление и год, круг со стрелкой. Дальше по макету (артборды 14, 21–23, 25) → факты (лого клиента, Категория/Клиент/Локация/Год/Формат/Услуги/Сайт, лид) → серые секции → «Следующий проект» (фото по центру, линия прогресса; на полном прокруте фото улетает на место фото обложки следующего кейса).
Данные — `js/cases.js` (генерируется скриптом из выгрузки lp.median.agency; правки можно вносить прямо в файл). Секции `blocks`: `cut` (вырезанное фото + текст), `pairs` (три фото с контурными словами), `feature` (заголовок + фото + белая карточка), `text` (заголовок + текст на колонках 3–5), `stats` (цифры). `img` — фото обложки, `vid` — видео-обложка (`media/video/<id>.mp4` h.264 + `<id>.hevc.mp4` для браузеров с HEVC — если HEVC не меньше, там лежит тот же h.264; постер `<id>.webp` — статичная заглушка со старого median.agency; ≤1280px без звука; при загрузке страницы прелоадер из макета (знак median заполняется сверху вниз) скачивает все видео в память, не дольше 15 с; на видео-обложках нет наезда, заголовок баннера инвертируется (mix-blend difference); «Альфа Движ» дорисован с 15 до 30 кадров/с; играет в баннере и на обложке кейса только видимое, при «уменьшении движения» — фото), `light:1` — светлое фото (тёмный заголовок в «Следующем проекте»).
Kaspersky — полностью по макету, фото вытащены из .ai (`media/cases/`). Фото остальных кейсов lp.median.agency скачаны с Тильды (static.tildacdn.com), в webp: обложка `<id>-cover` (1920px), коллажи `pairs` без слов (`<id>-<n>-<k>`, 1280px), один короткий текстовый блок превращён в `feature` (`<id>-feature`). Без фото: MegaFon, WG Awards, Grid Girls (их нет на lp; median.agency с просроченным SSL не открывался), у VTB только обложка из макета.
Адрес кейса: `/<id>` (например `/median-site/southhub`); прямые ссылки отдаёт `404.html`, он передаёт путь главной через sessionStorage. Старые ссылки `?case=<id>` тоже работают (id из `CASES`). Открытие и переход к следующему кейсу добавляют запись в историю; «назад» и крестик возвращают к предыдущему кейсу или на главную; по прямой ссылке кейс открывается сразу.

Видео-обложки взяты со старого median.agency (`wp-content/uploads`, SSL просрочен — качать с `curl -k`): alfa-dvizh, southhub, alfa-battle, megafon, vtb, kaspersky, wg, gridgirls. YouTube облачному серверу отдаёт капчу (google.com/sorry), Kinescope отдаёт плейлист, но CDN kinescopecdn.net закрыт.

Превью в списке кейсов и плашка «следующий слайд» берут уменьшенные копии из `media/thumb/` (520 px) — при добавлении кейса с новой обложкой сделать и копию: `convert <обложка> -resize '520x>' -quality 72 media/thumb/<имя>.webp`.
