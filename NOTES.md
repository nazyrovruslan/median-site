# Заметки по проекту (для продолжения работы в новой сессии)

## Что это
Новый сайт median.agency по дизайну и ТЗ 2019 года (TZ_site_median.pdf в Google Drive, папка Median_site).
Статика без сборки: `index.html` + `css/style.css` + `css/fonts.css` + `js/main.js` + `fonts/` + `media/`.
Деплой: GitHub Pages через Actions при пуше в `main`. Адрес: https://nazyrovruslan.github.io/median-site/

## Правила работы
- Правки готовить локально, показывать, что изменилось; пушить/деплоить только по явной команде Руслана.
- После правок в CSS/JS поднимать номер `?v=` у подключений в `index.html`, иначе GitHub Pages до 10 минут отдаёт браузеру старый файл из кэша.
- Шрифты: заголовки Druk Wide Cyr Bold (700) и Medium (500), текст Euclid Circular A 400/500/700. Лежат в `fonts/`.
- Заголовки разделов — переменная `--h2`; контурные слова — класс `.o` (text-stroke).
- Сетка десктопа (≥821px) как в макете median_site 2.ai: поля `--gutter` = 1/12 ширины, между ними 5 колонок по 1/6 (на 1920: 160 + 5×320). Шапка и баннер используют свои поля `--pad`. Кегли на 1920: заголовки 95px (`--h2`), крупный текст 38px (`--lead`), карточки 17px (`--txt`), подписи 18px (`--ui`).

## Структура главной (сверху вниз)
1. Баннер: слайдер кейсов (массив `HERO` = первые 5 из `CASES`), слева чёрная полоса под логотип, снизу чёрная панель с Follow us и прогресс-баром (бар — скраббер пальцем/мышью).
   Плашка «Следующий проект» в правом нижнем углу (21% × 41% экрана, всегда с превью). Переход: плашка целиком переезжает на место баннера, новая плашка вырастает из угла (JS-цикл, `go()`).
   Десктоп: удержание мыши на обложке открывает кейс (кольцо-прогресс). Тач: тап. Свайп только справа налево.
2. LIVE COMMUNICATIONS — бегущая строка на JS (без швов). Клик → шоурил (пока заглушка `showreel()`). На тач-экранах у центра экрана слово LIVE заливается превью.
3. «Волны» — 4 контура из PDF визитки (`CARD`), в покое поочерёдно дышат, по ховеру/у центра экрана (тач) собираются в идеальные круги; на тач после полной метаморфозы в центре появляется бейдж «О нас».
4. «Внешним или внутренним» + кольцо «Все проекты» (магнит).
5. Три направления (серые экраны с сеткой): Внешние / Внутренние / Out of the list.
6. Все кейсы — список с фильтрами; на тач превью появляется у строки, проходящей центр экрана.
7. Собственные проекты: South HUB, «На свежем воздухе».
8. Футер Start a project (магнитный плюс, бриф в панели), строка: mailto → Follow us (раскрывается в строку) → © Median Agency.

## Страница кейса (панель `#casePanel`)
Вёрстка по макету (артборды 13, 14, 21–23, 25, 26): обложка — фото слева (39.4% ширины, 84.7% высоты), заголовок справа (строки сплошные/контурные), круг со стрелкой → факты (лого клиента, Категория/Клиент/Локация/Год/Формат/Услуги/Сайт, лид) → серые секции → «Следующий проект» (фото по центру, линия прогресса; на полном прокруте фото улетает на место фото обложки следующего кейса).
Данные — `js/cases.js` (генерируется скриптом из выгрузки lp.median.agency; правки можно вносить прямо в файл). Секции `blocks`: `cut` (вырезанное фото + текст), `pairs` (три фото с контурными словами), `feature` (заголовок + фото + белая карточка), `text` (заголовок + текст на колонках 3–5), `stats` (цифры). `img` — фото обложки, `light:1` — светлое фото (тёмный заголовок в «Следующем проекте»).
Kaspersky — полностью по макету, фото вытащены из .ai (`media/cases/`). Остальные кейсы lp.median.agency — только тексты: фото с Тильды из этого окружения не скачивались.
Адрес кейса: `/<id>` (например `/median-site/southhub`); прямые ссылки отдаёт `404.html`, он передаёт путь главной через sessionStorage. Старые ссылки `?case=<id>` тоже работают (id из `CASES`). Открытие и переход к следующему кейсу добавляют запись в историю; «назад» и крестик возвращают к предыдущему кейсу или на главную; по прямой ссылке кейс открывается сразу.

## Тач-устройства (hover:none)
Магнит и курсор-кольцо отключены; отклик нажатия — лёгкое сжатие. Эффекты от скролла: LIVE-превью, волны→круги+«О нас», превью в списке кейсов, зум фото направлений.
